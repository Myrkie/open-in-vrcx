# open-in-vrcx
A userscript to add various "Open in VRCX" buttons to the VRChat website.

# Requirements

Requires a userscript loader such as [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) or [Greasemonkey](https://wiki.greasespot.net/Greasemonkey) only one is required take your pick it's a personal preference do you own research, after one is installed click below to install this userscript.

# [Click here to install](https://github.com/Myrkie/open-in-vrcx/raw/refs/heads/mistress/Open%20in%20VRCX.user.js)
